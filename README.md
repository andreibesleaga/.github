# .github

Default community health files for the repositories under
[andreibesleaga](https://github.com/andreibesleaga). GitHub uses a file from here in any
repository that has no file of the same kind of its own.

| File | Purpose |
| --- | --- |
| [SECURITY.md](SECURITY.md) | How to report a security problem |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 and where to report conduct issues |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Issues first, pull request steps, licence of contributions |
| [SUPPORT.md](SUPPORT.md) | Where to ask a question or report a bug |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/) | Bug report and feature request forms |
| [.github/pull_request_template.md](.github/pull_request_template.md) | Pull request checklist |
| [LICENSE](LICENSE), [LICENSES/](LICENSES/) | Licensing notice: each repository's own licence first; otherwise GPL-3.0-or-later for code and CC BY-NC-ND 4.0 for everything else (full texts in `LICENSES/`) |

GitHub does not apply a `LICENSE` from this repository to other repositories. Each repository
keeps its own `LICENSE` file; the notice here covers this repository and states the terms for any
material of the author that has no licence of its own.

Contact: issues in the repository concerned, or <https://andreibesleaga.com/contact/>.
