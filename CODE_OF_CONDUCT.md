# Code of conduct

This code of conduct applies to every repository under
[andreibesleaga](https://github.com/andreibesleaga) that does not have its own `CODE_OF_CONDUCT.md`.

These projects adopt the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its full text sets the expected and the unacceptable behaviour, and its enforcement guidelines
(correction, warning, temporary ban, permanent ban) are the ones applied here.

In short: be respectful, assume good intent, keep discussion about the work, and do not harass,
insult or publish anyone's private information.

## Reporting

Report unacceptable behaviour privately, through either channel:

- a private report in the affected repository (its **Security** tab, then **Report a
  vulnerability**), where that repository has private reporting turned on;
- the contact page of the maintainer's website, <https://andreibesleaga.com/contact/>.

Do not report it in a public issue. Every report is reviewed, and the reporter's privacy is
respected.
