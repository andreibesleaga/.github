# Security policy

This policy applies to every repository under [andreibesleaga](https://github.com/andreibesleaga)
that does not have its own `SECURITY.md`.

## Reporting a problem

Open an issue in the affected repository. Describe what you found and how to reproduce it, but do
not post working exploit code, secrets or personal data in the issue. That is the only contact
channel.

## Responsibility

These are personal open-source projects, provided as is and without warranty, as stated in each
repository's licence. Security fixes are made on a best-effort basis, with no guaranteed response
time and no support commitment. Only the latest version on the default branch is maintained;
archived repositories and older releases are not. You are responsible for reviewing and securing
any code you deploy.
